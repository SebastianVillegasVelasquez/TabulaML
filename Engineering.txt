2️⃣ Cómo pensar la ingeniería del sistema (mentalidad correcta)

No pienses “archivos”, piensa responsabilidades.

API Layer        → FastAPI endpoints
Application      → Orquestación del experimento
Domain (ML)      → Lógica de entrenamiento y evaluación
Infrastructure  → IO, serialización, storage
